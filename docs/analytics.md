# GrowthSent — First-Party Privacy Analytics

## Privacy Principles
1. **No PII Collected**: GrowthSent never collects IP addresses, names, email addresses, or form field inputs.
2. **No Keystroke Tracking**: No keylogging, input tracking, or session recording.
3. **Minimal Telemetry**: Ingests only page URL, referrer, anonymous visitor ID, session ID, and device/browser category.
4. **Data Retention**: Raw events are automatically expired after 90 days via MongoDB TTL indexes.
